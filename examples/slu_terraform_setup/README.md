# slu terraform setup example

`slu terraform setup` runs `terraform init` with the [GitLab managed Terraform state](https://docs.gitlab.com/user/infrastructure/iac/terraform_state/) backend (HTTP backend), configured from `.sikalabs/terraform/terraform.yaml` (or `terraform.json`).

## Config

[.sikalabs/terraform/terraform.yaml](.sikalabs/terraform/terraform.yaml)

```yaml
Meta:
  SchemaVersion: "1"
GitlabURL: "https://gitlab.sikademo.com"
ProjectID: "53"
StateName: "default"
```

- `GitlabURL` - URL of the GitLab instance
- `ProjectID` - ID of the GitLab project which stores the state
- `StateName` - name of the Terraform state in the project

Optional fields:

- `VaultAddr` - Vault address, required when `FilesInVault` is used
- `FilesInVault` - map of local file path to Vault secret path, files are downloaded from Vault (OIDC login) before `terraform init`
- `FilesWithCustomTooling` - map of file name to `{Get: "<shell command>"}`, the command is executed before `terraform init`

```yaml
VaultAddr: "https://vault.sikademo.com"
FilesInVault:
  terraform.tfvars: "secret/terraform/example/terraform.tfvars"
FilesWithCustomTooling:
  secrets.auto.tfvars:
    Get: "op read op://employee/example/secrets.auto.tfvars > secrets.auto.tfvars"
```

## Create the config

The config file can be generated by:

```
slu terraform create-setup-config https://gitlab.sikademo.com 53 default
```

Use `--format json` to create `terraform.json` instead of `terraform.yaml`.

## Run the setup

```
cd examples/slu_terraform_setup
slu terraform setup
```

GitLab credentials are resolved in this order:

1. `--username` / `--token` flags
2. 1Password item `GITLAB_TOKEN_TF_STATE_<gitlab-domain>` (eg. `GITLAB_TOKEN_TF_STATE_gitlab.sikademo.com`) in the `employee` vault, username is set to `token`
3. stdin (username and token, one per line) or interactive prompt

```
printf "token\n$GITLAB_TOKEN\n" | slu terraform setup
```

Additional arguments are passed to `terraform init`:

```
slu terraform setup -- -reconfigure
```

Print the `terraform init` command without executing it:

```
slu terraform setup --dry-run
```

Skip downloading files from Vault and custom tooling:

```
slu terraform setup --skip-files
```
